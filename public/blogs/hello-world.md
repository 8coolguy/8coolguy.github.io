## Format

Each post is a markdown file with front matter at the top:

```markdown
---
title: Post title
year: 2026
tags:
  - tag one
  - tag two
---

The body of the post.
```

Only the `title`, `year`, and `tags` fields are used by the blog page. `year` controls which year-group the post appears under.
